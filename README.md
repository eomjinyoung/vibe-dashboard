# 판매 대시보드

판매 데이터 엑셀 파일을 올리면 매출 현황을 지표와 차트로 보여 주는 웹 대시보드다. [Streamlit](https://streamlit.io)으로 만들었고, 웹 브라우저에서 동작한다.

## 기능

- **엑셀 파일 올리기**: 화면에서 `.xlsx` 파일을 올리면 대시보드가 나타난다. 올리기 전에는 안내 문구만 보인다.
- **핵심 지표**: 총 매출(원), 판매 건수(건), 건당 평균 매출(원)을 천 단위 쉼표를 넣어 보여 준다.
- **차트**
  - 월별 매출(선 차트)
  - 지역별 매출(막대 차트, 매출이 작은 지역부터)
  - 매출 상위 10개 상품(가로 막대 차트)
- **필터**(왼쪽 사이드바)
  - 지역: 여러 지역을 골라 볼 수 있다. 처음에는 모든 지역이 선택되어 있다.
  - 기간: 시작 월과 끝 월을 슬라이더로 고른다. 처음에는 데이터의 전체 기간이다.
  - 필터를 바꾸면 지표, 차트, 표가 모두 고른 조건에 맞게 바뀐다.
- **데이터 표**: 맨 아래 "데이터 보기"를 누르면 고른 조건에 맞는 판매 데이터를 표로 볼 수 있다.

## 엑셀 파일 형식

첫 번째 시트의 첫 줄에 아래 열 이름이 있어야 한다. 한 줄이 판매 한 건이다.

| 열 이름 | 내용 | 예 |
|---|---|---|
| 날짜 | 판매 날짜 | 2026-01-01 |
| 지역 | 판매 지역 | 서울 |
| 상품 | 상품 이름 | 기계식 키보드 |
| 수량 | 판매 수량 | 2 |
| 단가 | 한 개 가격(원) | 120000 |
| 매출 | 수량 × 단가(원) | 240000 |

`data/sales_2026.xlsx`는 이 형식으로 만든 예시 파일이다(2026년 1~6월, 1,000건).

## 설치

[uv](https://docs.astral.sh/uv/)가 설치되어 있어야 한다. 설치되어 있지 않으면 터미널에서 아래 명령으로 설치한다(macOS/Linux).

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

Windows는 PowerShell에서 아래 명령을 실행한다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

프로젝트 폴더로 이동한 뒤, 필요한 패키지(streamlit, pandas, openpyxl)를 설치한다. 알맞은 버전의 파이썬이 없으면 uv가 함께 설치한다.

```bash
uv sync
```

## 실행

```bash
uv run streamlit run app.py
```

실행하면 웹 브라우저에 대시보드가 열린다. 자동으로 열리지 않으면 터미널에 표시된 주소(보통 http://localhost:8501)를 브라우저에 입력한다.

화면에서 엑셀 파일(예: `data/sales_2026.xlsx`)을 올리면 대시보드가 나타난다. 끝내려면 터미널에서 `Ctrl + C`를 누른다.
